# Обновление 2.1 — 28.10.2026

- Исправлен HTTP-клиент Next.js JSON: отдельная сессия без Origin/Referer с User-Agent Mozilla/5.0, как в успешной проверке из PowerShell.
- HTTP 403 теперь корректно определяется как отказ доступа, а не автоматически как устаревший buildId.
- При HTTP 404 выполняется однократная попытка обнаружить обновлённый buildId.
- Добавлен `python -m scripts.check_next_json` для диагностики разных профилей заголовков на одном и том же URL.
- Обновлены тесты строгой проверки заголовков HTTP (20 тестов).

**Ограничение:** сервер PropertyHub может блокировать JSON независимо от заголовков. Если минимальный профиль тоже возвращает 403, получение подробностей и городских зон пока не подтверждено. Тесты с MockTransport не заменяют живую проверку.

# Обновление 2.0 — 28.10.2026

- «Подробнее» загружает Next.js JSON и фотогалерею вместо HTML 403.
- Пагинация без искусственного лимита 100 объявлений; следующие страницы по запросу.
- Корректное удаление пустого состояния при выходе и управляемая догрузка.
- Полностью пустой профиль по умолчанию, независимые поисковые и постоянные настройки.
- Подборки выполняют живой поиск с текущими постоянными настройками.
- Городской поиск через JSON-страницы PropertyHub и серверные `zoneIds` (требует живой проверки).
- 53 приблизительных районных кластера для 5 городов, редакционные оценки и фильтр районов.
- Отображение депозита и предоплаты, фильтр максимального депозита.
- Фильтр периода публикации.
- Новый рейтинг из 9 факторов с постоянным ухудшением компонента свежести.
- Батчевое чтение SQLite, время жизни кеша подробностей 24 часа.
- Добавлены тесты (19 локально проходят, в том числе офлайн smoke-тесты UI потока).

## Ограничения, требующие реальной проверки

- У PropertyHub неофициальный API. Реальные `zoneIds` страниц городов, успешность пустых фильтров на сайте и Next.js buildId после релиза не могут быть гарантированы без живого тестирования с доступом к PropertyHub.
- Районные кластеры приблизительные, не являются административными геополигонами.
- Рейтинг районов — редакционная оценка удобства длительного проживания, не объективный индекс.
- Telegram с реальным токеном в среде разработки не запускался.
